# Design vocabulary

Range to pull from when a request feels like it's drifting toward the default. Never apply a label
literally — translate it into layout, typography, color, surfaces, shapes, interaction, imagery,
motion, transitions and micro-interactions.

### Four worked starting points

- **Swiss / editorial** — strong typography, asymmetrical editorial grid, restrained palette,
  oversized type, thin rules, intentional negative space, magazine hierarchy.
- **Neo-brutalist** — hard borders, sharp geometry, high contrast, oversized controls,
  unconventional alignment, raw hierarchy, deliberately imperfect composition.
- **Soft clay** — inflated surfaces, soft shadows, tactile controls, rounded geometry, playful
  depth, physical-object metaphor.
- **Futuristic glass** — translucent surfaces, atmospheric backgrounds, layered depth, subtle blur,
  luminous accents, spatial navigation, restrained reflections.
- **Art-directed / experimental** — unusual composition, unexpected navigation, motion-led
  interaction, unconventional typography, visual storytelling, asymmetry, custom graphics.

## Layout systems

Centered composition · asymmetric editorial grid · full-screen canvas · split-screen ·
sidebar-centric · command-center · floating panels · layered spatial UI · horizontal storytelling ·
vertical narrative · modular grid · masonry · overlapping composition · edge-to-edge · dense
information architecture · single-focus interface · infinite canvas · dashboard cockpit · timeline ·
map-like spatial organization

Do not reuse the same layout structure for every request.

## Typography

Typography is a design tool, not decoration, and can be part of the composition itself: oversized
display type · condensed · grotesk and neo-grotesk · serif + sans pairings · mono · editorial ·
variable fonts · extreme weight contrast · tight tracking · generous tracking · vertical type · text
as graphical element.

## Color

Avoid the reflexes: blue + white, purple gradient, dark navy SaaS, black + electric blue.

Intentional systems: monochrome · warm neutral · black + acid accent · cream + red · cobalt +
off-white · muted industrial · pastel tactile · cinematic dark · high-contrast poster · earthy
organic · metallic · fluorescent · grayscale + one accent.

Color must support the product's personality.

## Motion language

Define motion up front, as a coherent system — not animations bolted on at the end.

- **Entrance** — fade · slide · scale · clip reveal · stagger · blur-to-sharp · mask reveal ·
  directional movement
- **Interaction** — magnetic cursor · hover transformation · elastic movement · physics-like
  response · morphing · parallax · depth movement · state transition
- **Navigation** — shared-element transition · spatial movement · horizontal scene transition ·
  expanding panel · morphing navigation · contextual transformation
- **Feedback** — tactile press · spring · ripple · micro-shake · progress transformation · state morph
- **Storytelling** — scroll-driven animation · pinned scenes · progressive reveal · visual timeline ·
  image transformation · typography animation

## Interaction concepts

Beyond click / modal / hover card / dropdown: drag · swipe · magnetic interaction · keyboard-driven
navigation · command palette · spatial navigation · progressive disclosure · contextual controls ·
inline editing · gestures · expandable surfaces · morphing interfaces · draggable collections ·
zooming · scroll storytelling · timeline interaction · canvas interaction · hover-based information
layers.

Interaction should reinforce the product concept.

## Creative randomizer

For open-ended requests, combine dimensions deliberately:

> layout + typography + material + color + interaction + motion + metaphor

e.g. *editorial layout + condensed typography + translucent material + monochrome palette + spatial
navigation + slow parallax + archive metaphor.*

Unusual but coherent. Never combine incompatible styles just to look creative.

## Quality bar

The result should feel specific · intentional · memorable · coherent · usable · visually distinctive ·
technically implementable · emotionally appropriate.

The goal is not "make it look fancy." The goal is: **give the product a visual point of view.**
